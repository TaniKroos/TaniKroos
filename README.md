## 🚀 Projects

### Steve: Cloud-Native Autonomous AI Coding Agent
An AI agent that edits code inside an isolated E2B sandbox and opens a real GitHub pull request, end to end.
- Full-stack: Python, FastAPI, React, TypeScript
- Multi-provider LLM abstraction (Anthropic, Azure OpenAI, OpenAI-compatible hosts)
- Crash-recoverable session ownership with Redis-backed sticky routing, so the agent runs as multiple horizontally scaled instances
- Live output to the browser via Redis pub/sub and Server-Sent Events

🌐 **Live demo:** [smudgee.xyz](https://www.smudgee.xyz/)

### JobSeeker: AI Job Application Assistant (MCP)
Connects Claude and ChatGPT to your browser: the assistant finds jobs and drafts answers, and a Chrome extension fills the application form in your own session. It never submits; you review and submit yourself.
- MCP server on Cloudflare Workers (TypeScript, Hono, D1, Durable Objects) exposing 11 tools
- Job search across 8 applicant tracking systems: Greenhouse, Lever, Ashby, Workday, SmartRecruiters, Workable, Recruitee, Oracle
- Chrome MV3 extension (WXT) that fills custom dropdowns, date pickers and multi-page Workday/Oracle flows
- Real-time routing to the right browser tab over WebSocket, one Durable Object per user
- Privacy-first: the server stores only your account email and a 90-day application list

🌐 **Live:** [jobs.smudgee.xyz](https://jobs.smudgee.xyz)
